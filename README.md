# Productivity

Aplikasi productivity pribadi berbasis web untuk dipakai sendiri. Tahap pertama: daftar tugas.

## Cara menjalankan

Butuh **Python 3.8 atau lebih baru**. Tidak perlu memasang apa pun lagi.

```
python3 server.py
```

(Di Windows, ketik `python server.py`.)

Browser akan terbuka otomatis ke **http://localhost:8000**. Tekan `Ctrl+C` di terminal untuk menghentikan server.

## Menjalankan uji otomatis

```
python3 -m unittest
```
